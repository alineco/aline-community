# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Be respectful in issues, pull requests and reviews. The maintainers may edit or remove comments, and block contributors, that break these rules.

To report a problem, use [GitHub's private vulnerability reporting](https://github.com/alineco/aline-community/security/advisories/new) or contact a maintainer listed in [CODEOWNERS](.github/CODEOWNERS). Reports are kept confidential.
