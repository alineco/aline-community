## What You'll Receive

A focused version comparison including:

1. **Summary of Changes** (3-4 sentences): Overview of major changes and direction (better/worse for us)
2. **Key Changes Analysis**: Material changes organized by category with impact assessment
3. **Favorable Changes**: Improvements for our position
4. **Unfavorable Changes**: Changes that weaken our position or add risk
5. **Recommendation**: Accept / Negotiate further / Reject

## Analysis Instructions

**Provide a clear version comparison focusing on material changes:**

### 1. Summary of Changes

In 3-4 sentences: How many material changes? General direction (more favorable/less favorable for us)? Major categories affected? Overall assessment of revisions.

### 2. Material Changes by Category

For **each selected focus area**, identify and analyze key differences in table format:

| Provision       | Version 1 Said   | Version 2 Says   | Impact | Significance | Analysis            |
| --------------- | ---------------- | ---------------- | ------ | ------------ | ------------------- |
| \[Section name] | \[Summary/quote] | \[Summary/quote] | 👍👎➖  | 🔴🟡🟢       | \[Why this matters] |

**Impact Guide:**

* 👍 Favorable (better for our position)
* 👎 Unfavorable (worse for our position)
* ➖ Neutral (no material impact)

**Significance Guide:**

* 🔴 High (material business impact)
* 🟡 Medium (worth noting)
* 🟢 Low (minor change)

**Financial Terms:**

* Pricing changes
* Payment term modifications
* New fees or changed fee structures
* Expense allocations

**Liability & Indemnification:**

* Liability cap changes
* New carve-outs or removed exceptions
* Indemnification scope changes
* Insurance requirement modifications

**Scope of Work:**

* Services added or removed
* Deliverable changes
* Specification modifications
* Acceptance criteria changes

**Term & Termination:**

* Contract duration changes
* Renewal term modifications
* Termination right changes
* Notice period changes

**IP & Data Rights:**

* Ownership changes
* License scope modifications
* Data usage right changes
* Confidentiality obligation changes

### 7. Recommendation

**Overall Assessment:**

* ✅ **Accept Version 2** — Changes are acceptable, proceed with signing
* 🟡 **Negotiate Further** — Some unfavorable changes need to be addressed
* 🔴 **Reject Version 2** — Significant unfavorable changes, push back strongly

​

Include brief rationale (2-3 sentences) and list top 3 points to negotiate if applicable.

​

**Output Guidelines:**

* Focus on material changes, not minor wording tweaks
* Clearly mark each change as favorable/unfavorable/neutral
* Be specific about impact on our position
* Prioritize changes by business significance
* If many changes, group similar items
* Skip sections with no material changes
* Provide context: "This change shifts risk from us to them because..."
* Only analyze selected focus areas unless "all material changes" is selected
