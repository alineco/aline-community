## What You'll Receive

A properly formatted unanimous written consent (or written consent) including:

1. **Title & Header**: Proper legal caption with company name and date
2. **Introductory Paragraph**: Statutory authority and consent statement
3. **Resolutions by Matter**: Each approval item with WHEREAS clauses and RESOLVED clauses
4. **Conflict Recusal** (if applicable): Formal acknowledgment of recusal
5. **Omnibus Resolutions**: Officer authorization and ratification provisions
6. **Signature Blocks**: One for each board member with date lines
7. **Exhibits**: Reference to attached documents

## Drafting Instructions

**Generate a formal board consent following these guidelines:**

### 1. Document Header
Format: [UNANIMOUS] WRITTEN CONSENT OF THE BOARD OF [DIRECTORS/MANAGERS] OF [COMPANY NAME], with Effective Date

### 2. Introductory Paragraph
- State statutory authority based on entity type and jurisdiction
- Corporations: Reference applicable state corporate statute (e.g., DGCL § 141(f))
- LLCs: Reference applicable state LLC statute
- Include consent statement: "The undersigned, constituting [all of / a majority of] the members of the Board... hereby consent to the following resolutions..."

### 3. Resolution Format for Each Matter
For each approval item, use this structure:
- Section number with Roman numerals (I, II, III, etc.)
- Title that clearly describes the matter
- WHEREAS clauses (2-4 typically) providing background and context
- NOW, THEREFORE, BE IT RESOLVED clause with specific authorization
- RESOLVED FURTHER clause if additional authorization needed

**Guidelines:**
- WHEREAS clauses provide context (one sentence each)
- RESOLVED clauses contain the actual authorization/approval
- Be specific about what's being approved
- Reference exhibits if documents are attached

### 4. Conflict of Interest Section (if applicable)
Only include if a board member is recused:
- Section with appropriate Roman numeral
- WHEREAS clauses acknowledging the conflict and recusal
- RESOLVED clause accepting the recusal in accordance with law and governing documents

### 5. Omnibus Resolutions (Always Include)
Final section authorizing officers to implement:
- RESOLVED clause authorizing officers to take necessary actions to effectuate resolutions
- RESOLVED clause ratifying any prior actions taken to carry out resolutions

### 6. Execution Paragraph
- IN WITNESS WHEREOF statement
- Note about counterpart execution
- Statement that consent shall be filed with board minutes

### 7. Signature Blocks
Create one signature block for each board member with:
- Signature line
- Name and title ([Director/Manager Name], [Director/Manager])
- Date line

### 8. Exhibits
If documents are attached, list them as Exhibit A, Exhibit B, etc. with titles

**Output Guidelines:**
- Use formal legal language appropriate for corporate records
- Number sections with Roman numerals (I, II, III, etc.)
- Use proper whereas/resolved format
- Be specific in resolutions (avoid vague authorizations)
- Keep WHEREAS clauses concise (one sentence each)
- Ensure resolutions clearly authorize the intended action
- Format professionally for execution and filing
